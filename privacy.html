Sales Link Operations

Privacy Policy

Last Updated: October 12, 2026 • Effective Immediately

1. Overview

Sales Link ("we", "our", or "platform") is an internal retail lending sales execution and file tracking management system accessible at https://saleslink.in. This Privacy Policy outlines how authorized user information is collected, processed, and safeguarded.

2. Information We Collect

When authorized personnel sign in using Google Single Sign-On (OAuth), we collect:

  • Identity Information: Name, work email address, and profile photo provided by Google.
  • Operational Data: Loan file records, customer applicant names, tracking statuses (login, sanction, disbursement), and daily sales End-of-Day (EOD) submissions.
  • Technical Logs: Browser session timestamps and IP access records strictly for authentication and security audits.

3. How Information Is Used

Data collected within Sales Link is utilized exclusively for:

  • Authenticating Sales Managers and Relationship Officers (ROs).
  • Tracking retail asset file turnaround times and managing branch loan pipelines.
  • Generating branch sales summaries and team performance dashboards.

We do not sell, rent, monetize, or share user or customer data with any third-party advertisers or commercial entities.

4. Data Storage & Security

All application records are securely encrypted in transit using 256-bit SSL/TLS protocol and stored within enterprise-grade Google Cloud Firestore database infrastructure with role-based access control.

5. Google API Services User Data Policy

Sales Link's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
